# HR-Stack–Employee Onboarding System

## Requirements

- Spring Boot application
- PostgreSQL database
- Employee registration API
- Auto-generated Emp ID
- Swagger

## Employee Fields

- Employee ID (Auto-generated)
- First Name
- Last Name
- Email
- Mobile Number

## tech stack

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Swagger

## API

POST `/employee/register` – Registers a new employee.

## Database

- **Database:** `employee_db`
- **Table:** `employee`
